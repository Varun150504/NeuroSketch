✦ About This Project

A College Project Powered by AI

NeuroSketch was built as a Generative AI course project to explore how large language models can transform abstract knowledge into interactive visual experiences.

It integrates Google's Gemini 1.5 Flash model to generate semantically rich concept maps, creative narratives, and quiz questions — all in real-time, from any topic.

🧠
Google Gemini 1.5 Flash Concept generation & storytelling
🎨
HTML5 Canvas API Interactive mind map rendering
